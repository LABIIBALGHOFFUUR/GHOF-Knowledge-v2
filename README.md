# GHOF KNOWLEDGE — GitHub Pages

Upload semua isi folder ini ke repository GitHub.

File utama:
- index.html = website publik
- admin.html = admin panel terpisah
- assets/kursus.jpg = Foto 1, visual kursus
- assets/logo.jpg = Foto 2, logo website
- assets/ceo.png = Foto 3, pemilik/CEO

URL publik:
https://USERNAME.github.io/REPOSITORY/index.html

URL admin:
https://USERNAME.github.io/REPOSITORY/admin.html

Password admin awal:
GHOF2026

Catatan penting:
Ini versi static/front-end tanpa API key, database, atau backend. Data yang diedit melalui admin panel disimpan di localStorage browser. Karena itu, perubahan admin tidak menjadi database bersama untuk semua pengunjung. Untuk GitHub Pages murni tanpa backend, ini adalah batasannya.

Jika ingin mengubah password, edit ADMIN_PASS di admin.js.
