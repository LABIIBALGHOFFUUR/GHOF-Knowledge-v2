# GHOF KNOWLEDGE Website

Website resmi **GHOF KNOWLEDGE** (*GHOF Language Academy & Digital Solutions*) yang mencakup:
- **GHOF Russian Class** (Kelas Gratis & Kelas Berbayar Promo Pembukaan)
- **Katalog E-Book Pembelajaran Bahasa**
- **Jasa Pembuatan Website** (Sekolah, Jualan/Toko Online, Portofolio, Company Profile)
- **Admin Panel Terpisah (`admin.html`)**

## Cara Pasang di GitHub Pages
1. Buka repositori GitHub kamu (`GHOF-Knowledge-v2`).
2. Upload keempat file (`index.html`, `admin.html`, `style.css`, dan `data.js`) ke folder utama (*root*) repositori.
3. Buka menu **Settings > Pages**, pilih branch `main` dan folder `/ (root)`, lalu klik **Save**.
4. Akses halaman publik di: `https://labiibalghoffuur.github.io/GHOF-Knowledge-v2/index.html`
5. Akses halaman admin khusus kamu di: `https://labiibalghoffuur.github.io/GHOF-Knowledge-v2/admin.html` (Password default: `ghof2026`).

## Cara Sinkronisasi Perubahan Admin ke Semua Pengunjung
1. Login ke `admin.html`, upload foto atau edit produk/harga sesuai keinginan.
2. Klik tombol **Download data.js untuk GitHub**.
3. Upload file `data.js` hasil unduhan tersebut ke repositori GitHub kamu untuk menggantikan file `data.js` yang lama.
4. hasilnya di bawah ini
   https://labiibalghoffuur.github.io/GHOF-Knowledge-v2/
