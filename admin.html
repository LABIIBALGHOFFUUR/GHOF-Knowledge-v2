Metode Pembayaran

Cara Sinkronisasi ke Link Publik GitHub:

1. Edit data di atas (tambah/hapus e-book, ubah harga, tutup/buka katalog) lalu klik Simpan.
2. Klik tombol hijau Download data.js Terbaru di kanan atas.
3. Upload file data.js tersebut ke repositori GitHub kamu (timpa file data.js lama) agar semua pengunjung di link publik langsung melihat pembaruannya!
