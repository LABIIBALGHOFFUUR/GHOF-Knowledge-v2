FAQ

Pertanyaan yang sering ditanyakan

Bagaimana cara daftar kursus?

Pilih paket kursus, pilih metode pembayaran, lalu lanjutkan chat admin melalui WhatsApp untuk mendapatkan informasi pembayaran dan pendaftaran.

Apakah ada kelas gratis?

Ya. Tersedia FREE RUSSIAN CLASS dengan fasilitas dasar.

Bagaimana membeli ebook?

Pilih ebook, pilih metode pembayaran, kemudian lanjutkan chat admin untuk mendapatkan instruksi pembayaran.

Website apa saja yang bisa dibuat?

Contohnya website sekolah, website jualan, portfolio, company/profile usaha, landing page, dan website custom.

Apakah metode pembayaran bisa berubah?

Ya. Daftar metode pembayaran dapat dikelola melalui admin panel.
